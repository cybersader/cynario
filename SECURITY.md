# Security policy

Cynario keeps Scenarios in the browser. Protected sharing encrypts content client-side, so no
server sees plaintext. We take reports against those guarantees seriously.

## Reporting a vulnerability

Please **do not open a public issue** for a security problem.

Report it privately through GitHub:
[Report a vulnerability](https://github.com/cybersader/cynario/security/advisories/new).

Helpful details:

- what you found and where (page, feature, or share-link flow)
- steps to reproduce
- the app version shown in the Builder menu (for example `Cynario v0.9.0-alpha.1 (abc1234)`)

Please don't include real sensitive Scenario content, live share links, or passwords. A
minimal made-up example is enough.

## Supported versions

Cynario is in alpha. Only the version currently deployed at [cynar.io](https://cynar.io) is
supported.
